# soil-water · 土水池沼

> **土克水**：土（黄）与水（黑）如天平两侧，平衡而不相侵，如池沼。

- 背景：土金 `#C9A45C` → 深水 `#1A2330` 渐变，主色 `#8A7350`。
- 面板：深橄榄玻璃 `#3A382E → #1A1A14`，白高光描边 `rgba(255,255,255,.16)`。
- 点缀：土黄 `#E0A93C` / 水黑 `#1A1E28`。
- 线/前景：`#EFE9DC`；圆角 16-18px。
- 玻璃规范：磨砂半透（blur 14px / sat 140%）+ 顶部亮底部透 + 白高光描边 + 边缘高光（与 water-wood-flame 一致）。
