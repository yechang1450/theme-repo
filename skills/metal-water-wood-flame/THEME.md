# metal-water-wood-flame · 金水木火

> 金（白）→ 水（黑）→ 木（青）→ 火（赤）四行，融合态。

- 背景：焰玫 `#B06A6E` → 深酒 `#2E1620` 渐变，主色 `#C4656A`。
- 面板：深酒玻璃 `#402E30 → #1E1012`；点缀：金白 `#E9EAF0` / 水黑 `#1A1E28` / 木青 `#2BAE85` / 火赤 `#E5484D`。
- 线/前景：`#F0E2E2`；圆角 16-18px。
- 玻璃规范：磨砂半透（blur 14px / sat 140%）+ 顶部亮底部透 + 白高光描边 + 边缘高光（与 water-wood-flame 一致）。
