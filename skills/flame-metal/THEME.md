# flame-metal · 火金器皿

> **火克金**：火（赤）与金（白）如天平两侧，平衡而不相侵，如熔金为器。

- 背景：焰玫瑰 `#E5A9A5` → 深赤 `#7A3030` 渐变，主色 `#C88A7E`。
- 面板：深酒红玻璃 `#46302C → #201210`，白高光描边 `rgba(255,255,255,.16)`。
- 点缀：火赤 `#E5484D` / 金白 `#E9EAF0`。
- 线/前景：`#F5E6E2`；圆角 16-18px。
- 玻璃规范：磨砂半透（blur 14px / sat 140%）+ 顶部亮底部透 + 白高光描边 + 边缘高光（与 water-wood-flame 一致）。
