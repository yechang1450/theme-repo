# water-flame · 水火既济

> **水克火**：水（黑）与火（赤）如天平两侧达成完美平衡——即。

- 背景：火赤 `#D9605F` → 深水黑 `#2E1620` 渐变，主色 `#C4656A`。
- 面板：深酒红玻璃 `#402A2E → #1E1012`，白高光描边 `rgba(255,255,255,.16)`。
- 点缀：火赤 `#E5484D` / 水黑 `#1A1E28` / 白 `#FFE9E9`。
- 线/前景：`#F6E4E4`；圆角 16-18px。
- 玻璃规范：磨砂半透（blur 14px / sat 140%）+ 顶部亮底部透 + 白高光描边 + 边缘高光（与 water-wood-flame 一致）。
