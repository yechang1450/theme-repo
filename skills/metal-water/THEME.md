# metal-water · 金白水清

> **金生水**：金（白）生水（黑），两种能量完美融合，融合色为**灰**。

- 背景：灰渐变 `#B7BCC4 → #3A4048`，主色 `#8E939B`。
- 面板：半透明毛玻璃 `rgba(255,255,255,0.10)` → `rgba(22,26,30,0.55)`，白高光描边 `rgba(255,255,255,.18)`。
- 点缀：金白 `#E9EAF0` / 水黑 `#1A1E28` / 纯白 `#FFFFFF`。
- 线/前景：`#E4E8EE`；圆角 16px。
- 玻璃规范：磨砂半透（blur 14px / sat 140%）+ 顶部亮底部透 + 白高光描边 + 边缘高光（与 water-wood-flame 一致）。
