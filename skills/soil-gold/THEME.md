# soil-gold · 土金毓秀

> **土生金**：土（黄）生金（白），两种能量完美融合，融合色为**橙**。

- 背景：橙渐变 `#F0A45C → #7A4A1E`，主色 `#E8853D`。
- 面板：深琥珀玻璃 `#4A3A28 → #241A10`，白高光描边 `rgba(255,255,255,.16)`。
- 点缀：土黄 `#E0A93C` / 金白 `#E9EAF0` / 钢白 `#F2F2F5`。
- 线/前景：`#F9EEDD`；圆角 16-18px。
- 玻璃规范：磨砂半透（blur 14px / sat 140%）+ 顶部亮底部透 + 白高光描边 + 边缘高光（与 water-wood-flame 一致）。
