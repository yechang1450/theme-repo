# water-wood-flame-soil · 水木火土

> 水（黑）→ 木（青）→ 火（赤）→ 土（黄）四行，融合态。

- 背景：焰土 `#C98F4A` → 深水 `#2A2E12` 渐变，主色 `#B98A3E`。
- 面板：半透明毛玻璃 `rgba(255,255,255,0.10)` → `rgba(28,26,14,0.55)`；点缀：水蓝 `#4A8CFF` / 木青 `#2BAE85` / 火赤 `#E5484D` / 土黄 `#E0A93C`。
- 线/前景：`#F2EBD8`；圆角 16px。
- 玻璃规范：磨砂半透（blur 14px / sat 140%）+ 顶部亮底部透 + 白高光描边 + 边缘高光（与 water-wood-flame 一致）。
