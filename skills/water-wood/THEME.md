# water-wood · 水灵木秀

> **水生木**：水（黑）生木（青），两种能量完美融合，融合色为**蓝**。

- 背景：水蓝渐变 `#5B93FF → #123A66`，主色 `#3D7BFF`。
- 面板：深水玻璃 `#25354E → #121C2A`，白高光描边 `rgba(255,255,255,.16)`。
- 点缀：木青 `#2BAE85` / 青碧 `#38D0A0` / 钢白 `#E8EAF0`。
- 线/前景：`#DCEBFF`；圆角 16-18px。
- 玻璃规范：磨砂半透（blur 14px / sat 140%）+ 顶部亮底部透 + 白高光描边 + 边缘高光（与 water-wood-flame 一致）。
