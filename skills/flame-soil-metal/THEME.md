# flame-soil-metal · 火土金

> 火（赤）→ 土（黄）→ 金（白），三种能量融合态。

- 背景：琥珀金渐变 `#E0A96A → #6E5A3A`，主色 `#C99A5A`。
- 面板：深黄铜玻璃 `#4A3E2E → #241C10`，白高光描边 `rgba(255,255,255,.16)`。
- 点缀：火赤 `#E5484D` / 土黄 `#E0A93C` / 金白 `#E9EAF0`。
- 线/前景：`#F7F0E4`；圆角 16-18px。
- 玻璃规范：磨砂半透（blur 14px / sat 140%）+ 顶部亮底部透 + 白高光描边 + 边缘高光（与 water-wood-flame 一致）。
