# soil-metal-water · 土金水

> 土（黄）→ 金（白）→ 水（黑），三种能量融合态。

- 背景：沙金 `#C9B08A` → 深石板 `#2A2E38` 渐变，主色 `#9AA0A8`。
- 面板：深锡玻璃 `#3E4048 → #1C1E24`，白高光描边 `rgba(255,255,255,.16)`。
- 点缀：土黄 `#E0A93C` / 金白 `#E9EAF0` / 水黑 `#1A1E28`。
- 线/前景：`#ECECEA`；圆角 16-18px。
- 玻璃规范：磨砂半透（blur 14px / sat 140%）+ 顶部亮底部透 + 白高光描边 + 边缘高光（与 water-wood-flame 一致）。
