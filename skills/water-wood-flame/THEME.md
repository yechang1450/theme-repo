# water-wood-flame · 水木火

> 源于平衡理念，但最准确的叫法是**水木火**：水（黑）生木（青），木（青）生火（紫/赤），三种能量处于融合态。

- 火/背景：紫渐变 `#7B52F0 → #3A1E9E`，主色 `#6A3DE8`（木生火之紫），柔光斑蓝`#9BE8FF`/粉`#FF9BE8`。
- 水/面板：深蓝黑玻璃 `#2E3450 → #151A2B`（水之黑），白高光描边 `rgba(255,255,255,.18)`，标题条 `#39415C`。
- 木/点缀：绿`#a9e34b`（木之青）、蓝`#58a6ff`（水生木之蓝）、橙`#febc2e`、红`#ff5f57`、黄`#ffd43b`。
- 线/前景：`#E6ECFF`。
- 圆角：16-18px；玻璃面板为磨砂半透 + 顶部亮、底部透。
- 玻璃规范：磨砂半透（blur 14px / sat 140%）+ 顶部亮底部透 + 白高光描边 + 边缘高光（与 water-wood-flame 一致）。
