# flame-soil · 火土成慈

> **火生土**：火（赤）生土（黄），两种能量完美融合，融合色为**棕**。

- 背景：棕渐变 `#C07F5A → #5A3526`，主色 `#9A6B4F`。
- 面板：深赭玻璃 `#4A3328 → #241611`，白高光描边 `rgba(255,255,255,.16)`。
- 点缀：火赤 `#E5484D` / 土黄 `#E0A93C` / 钢米 `#E8E0D8`。
- 线/前景：`#F7E8DC`；圆角 16-18px。
- 玻璃规范：磨砂半透（blur 14px / sat 140%）+ 顶部亮底部透 + 白高光描边 + 边缘高光（与 water-wood-flame 一致）。
