# wood-soil · 木土疏通

> **木克土**：木（青）与土（黄）如天平两侧，平衡而不相侵，如疏通渠道。

- 背景：木青 `#7FC9A8` → 深土 `#6B4A1E` 渐变，主色 `#8FAE3E`。
- 面板：橄榄炭玻璃 `#3E4230 → #1C1E12`，白高光描边 `rgba(255,255,255,.16)`。
- 点缀：木青 `#2BAE85` / 土黄 `#E0A93C`。
- 线/前景：`#ECEFE0`；圆角 16-18px。
- 玻璃规范：磨砂半透（blur 14px / sat 140%）+ 顶部亮底部透 + 白高光描边 + 边缘高光（与 water-wood-flame 一致）。
