# metal-wood · 金木栋梁

> **金克木**：金（白）与木（青）如天平两侧，平衡而不相侵，如栋梁。

- 背景：金白 `#D9DEE4` → 深木 `#1E5C46` 渐变，主色 `#6FA58E`。
- 面板：半透明毛玻璃 `rgba(255,255,255,0.10)` → `rgba(26,32,28,0.55)`，白高光描边 `rgba(255,255,255,.18)`。
- 点缀：金白 `#E9EAF0` / 木青 `#2BAE85`。
- 线/前景：`#E8EEEA`；圆角 16px。
- 玻璃规范：磨砂半透（blur 14px / sat 140%）+ 顶部亮底部透 + 白高光描边 + 边缘高光（与 water-wood-flame 一致）。
