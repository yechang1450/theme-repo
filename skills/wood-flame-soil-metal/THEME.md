# wood-flame-soil-metal · 木火土金

> 木（青）→ 火（赤）→ 土（黄）→ 金（白）四行，融合态。

- 背景：琥珀金渐变 `#E0A96A → #6E5A3A`，主色 `#C99A5A`。
- 面板：半透明毛玻璃 `rgba(255,255,255,0.10)` → `rgba(36,28,16,0.55)`；点缀：木青 `#2BAE85` / 火赤 `#E5484D` / 土黄 `#E0A93C` / 金白 `#E9EAF0`。
- 线/前景：`#F7F0E4`；圆角 16px。
- 玻璃规范：磨砂半透（blur 14px / sat 140%）+ 顶部亮底部透 + 白高光描边 + 边缘高光（与 water-wood-flame 一致）。
