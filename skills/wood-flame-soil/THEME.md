# wood-flame-soil · 木火土

> 木（青）→ 火（赤）→ 土（黄），三种能量融合态。

- 背景：焰土渐变 `#D97A5A → #4A2E12`，主色 `#C18A3E`。
- 面板：深琥珀玻璃 `#46362A → #221810`，白高光描边 `rgba(255,255,255,.16)`。
- 点缀：木青 `#2BAE85` / 火赤 `#E5484D` / 土黄 `#E0A93C`。
- 线/前景：`#F7EBDC`；圆角 16-18px。
- 玻璃规范：磨砂半透（blur 14px / sat 140%）+ 顶部亮底部透 + 白高光描边 + 边缘高光（与 water-wood-flame 一致）。
