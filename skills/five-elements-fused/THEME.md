# five-elements-fused · 五行融合

> 木（青）、火（赤）、土（黄）、金（白）、水（黑）五行融合为一。

- 背景：融合沙灰渐变 `#B7A98F → #4A4035`，主色 `#97876E`（五行融合色，亦为 theme-repo 插件图标色）。
- 面板：暖炭玻璃 `#3E3A33 → #1C1A16`；点缀：五行五色（木青/火赤/土黄/金白/水黑）。
- 线/前景：`#EFE9DC`；圆角 16-18px。
- 玻璃规范：磨砂半透（blur 14px / sat 140%）+ 顶部亮底部透 + 白高光描边 + 边缘高光（与 water-wood-flame 一致）。
