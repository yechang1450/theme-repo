# wood-flame · 木火通明

> **木生火**：木（青）生火（赤），两种能量完美融合，融合色为**紫**。

- 背景：紫渐变 `#8E63F2 → #2E1A5E`，主色 `#7B52F0`。
- 面板：半透明毛玻璃 `rgba(255,255,255,0.10)` → `rgba(28,21,38,0.55)`，白高光描边 `rgba(255,255,255,.18)`。
- 点缀：木青 `#2BAE85` / 火赤 `#E5484D` / 钢白 `#E8EAF0`。
- 线/前景：`#EDE6FF`；圆角 16px。
- 玻璃规范：磨砂半透（blur 14px / sat 140%）+ 顶部亮底部透 + 白高光描边 + 边缘高光（与 water-wood-flame 一致）。
