# theme-repo

五行主题仓库：27 个主题色，每个主题一个独立 skill，图标=对应主题色；统一玻璃拟态设计 token。

## 用法

读取目标主题 skill 下的 `tokens.json`（fire/water/yang/line/radius + glass 玻璃层 + relation/elements），按 token 写 CSS 变量即可套用。

## 主题清单（27）

- 基础五行：wood / fire / soil / metal / water
- 完美相生：water-wood / wood-flame / flame-soil / soil-gold / gold-water
- 完美相克：gold-wood / wood-soil / soil-water / water-flame / flame-gold
- 三行连续：water-wood-flame / wood-flame-soil / flame-soil-gold / soil-gold-water / gold-water-wood
- 四行连续：water-wood-flame-soil / wood-flame-soil-gold / flame-soil-gold-water / soil-gold-water-wood / gold-water-wood-flame
- 特殊地支：wet-soil-gold
- 五行融合：five-elements-fused（#97876E，插件图标色）
