# water-flame · 水火既济（设计体系）

> 紫色为**丁火**（阴火），黑色为**癸水**（阴水）；阴火与阴水达成完美平衡，即「水火既济」。
> 用于 codex-tui-orchestrator / 80 / 81 / 82 等 UI 的统一视觉语言。（原名 ji-ji，已更名 water-flame）

## 命名
- `water-flame`（取自「水火既济」）：**紫(火) + 黑(水) 平衡**。
- 主色：丁火紫 `#6A3DE8`；辅底渐变 `#7B52F0 → #3A1E9E`。
- 水面板：深海军蓝玻璃 `#2E3450 → #151A2B`（顶部亮、底部深），营造「水覆火上」的平衡。

## 玻璃拟态规范
- 背景：紫渐变（丁火）+ 柔和蓝/粉光斑（景深）。
- 面板：深色半透玻璃（癸水）：顶 `#2E3450`（Alpha .95）、底 `#151A2B`（Alpha .98），圆角 + 轻微白高光描边（#fff 18%）。
- 标题条 / 内衬：`#39415C`。
- 高亮点缀：绿 `#a9e34b`、蓝 `#58a6ff`、橙 `#febc2e`、红 `#ff5f57`、黄 `#ffd43b`、青 `#9BE8FF`。
- 前景文字/线条：`#E6ECFF`（带透明度）。
